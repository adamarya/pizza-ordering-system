# Sprint 1 design prototypes

Standalone HTML prototypes that shaped the Sprint 1 screens. They run in a browser with sample
data and are kept here as design records; the application in `/client` is the working version.

| File | Author | Used for |
|---|---|---|
| `cart-prototype-emmanuella-ahinkrah.html` | Emmanuella Ahinkrah (pull request #2) | Layout, fulfillment toggle, tip options, and order summary of the cart screen (`/cart`) |
| `menu-prototype-aaron-aguirre.html` | Aaron Aguirre | Menu with category filter, item detail, and configuration with half-and-half toppings; its "Build Your Own Pizza" card is a candidate backlog item for the Product Owner |

Differences from the application: the prototypes price items in the browser with sample prices,
while the application shows only the server's quote in integer cents (Table 21). Promo codes in
the cart prototype are held for PB-14.
